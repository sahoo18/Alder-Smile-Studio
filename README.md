# Alder Dental Studio

A full one-page dental clinic website built with React and Vite.

## Features

- Responsive navigation
- Hero section
- Featured treatments
- Dental care standards
- Statistics section
- Call-to-action banner
- Dental gallery
- Blog section
- FAQ section
- Footer
- Custom dental images

## Technologies Used

- React
- Vite
- JavaScript
- CSS
